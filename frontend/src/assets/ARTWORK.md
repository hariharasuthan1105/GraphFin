# GraphFin environment artwork

portal-reference.webp is an environment-only derivative of the user-supplied GraphFin Neon Financial Intelligence reference, created with the built-in image generation tool for this project. All website navigation, headings and action controls are live React elements.

Prompt: Artwork-only edit of user GraphFin neon reference: preserve digital globe, crimson portal, city canyon and astronaut; remove all website headings, navigation, button and caption overlays; reconstruct underlying art; retain portrait composition.

portal.webp is an original generated city/network-portal environment, used for decorative application headers. Prompt: wide cinematic pixel-art financial server city, midnight navy and black, crimson transaction sphere, small astronaut, no UI or text.

No proprietary Apple fonts are bundled. Existing Pixelify Sans, Silkscreen and IBM Plex Mono licenses remain in research/fonts.
