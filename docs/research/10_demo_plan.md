## Rehearsal checklist

- Verify health, local API override and additive research Vite config; avoid the remote legacy API fallback.
- Inspect the 84-evaluation overview, both IBM populations and provenance badges.
- Show all six splits, separate model seeds, experiment metrics/provenance/ranking tabs and explicit versions.
- Use an E4 split42/model42 descending top20 graph link; keep fixed-scope/partial notices visible.
- Demonstrate node/edge selection, Fit/reset/pan/zoom and keyboard tables. A temporal subwindow must hide full-snapshot score/diagnostic annotations.
- For available saved evidence, use Diagnostics `crest-001` (method B in the pinned record), or a graph anchor marked compatible and an available row. Do not call all 24 rows available explanations.
- Download the selected report, check filename/title and open four pages. PDF date 2000-01-01 is an invariant metadata sentinel, not the run/download date.
- Keep PaySim graph unavailable and both label identities visible; never substitute an invented graph.
- End with three separate readiness decisions. Do not imply certified crime detection or IEEE acceptance.
